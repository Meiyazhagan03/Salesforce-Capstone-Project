🐾 PetCare Connect – Veterinary & Pet Owner Relationship Management CRM

PetCare Connect is a Salesforce-based CRM application designed to strengthen the relationship between veterinary clinics and pet owners. Built using Lightning Web Components, Flows, Apex, and Automation tools, it provides a unified platform to manage pets, owners, veterinarians, medical records, and appointments efficiently.

The system automates appointment scheduling, vaccination reminders, medical record tracking, and treatment approvals — ensuring a seamless experience for both veterinarians and pet owners. With real-time dashboards and reports, clinics can monitor operations, track upcoming appointments, and analyze service performance.

This capstone project was developed as part of my Salesforce Developer Virtual Internship by SmartBridge in collaboration with Salesforce, showcasing a real-world CRM implementation in the healthcare domain.
